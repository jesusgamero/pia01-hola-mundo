# PIA01 - Hola Mundo

Repositorio de la tarea 1 del módulo **Programación de Inteligencia Artificial** (Curso de Especialización en Inteligencia Artificial y Big Data).

## Sobre la tarea

La tarea consiste en empezar a tener presencia en la comunidad de desarrollo de inteligencia artificial. Para ello hay que:

- Crear una cuenta en GitHub y un primer repositorio con este README y un "Hola Mundo" en Python.
- Conectar con la comunidad de IA a través de redes sociales (en mi caso, LinkedIn).

## Archivos

- `README.md`: explicación de la tarea.
- `hola_mundo.py`: programa que muestra un saludo por pantalla.

## Ejecución

python hola_mundo.py
